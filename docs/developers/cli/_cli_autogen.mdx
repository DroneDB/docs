### 3dtiles

```
Generate OGC 3D Tiles (tileset.json + b3dm) from 3D models (OBJ/GLTF/GLB/PLY/STL) using Obj2Tiles.
Usage:
  ddb 3dtiles model.obj [output_dir] [args]

  -i, --input arg       Model to process (OBJ/GLTF/GLB/PLY/STL)
  -o, --output arg      Output 3D Tiles directory (defaults to a 3dtiles/ 
                        folder next to the input)
      --lat arg         Latitude of the model origin (WGS84). With --lon, 
                        forces a georeferenced tileset
      --lon arg         Longitude of the model origin (WGS84). With --lat, 
                        forces a georeferenced tileset
      --alt arg         Altitude of the model origin in meters (used with 
                        --lat/--lon) (default: 0)
      --local           Force a non-georeferenced (local) tileset, skipping 
                        sidecar auto-detection
      --force-defaults  Skip face-count heuristic and use default Obj2Tiles 
                        parameters (divisions=3, lods=3, octree=true) for 
                        testing
      --overwrite       Replace the output if it already exists
  -h, --help            Print help
      --debug           Show debug output

```

### align

```
Align a GeoTIFF (ortho or DEM) to a reference GeoTIFF, correcting georeferencing offset.
Usage:
  ddb align -i source.tif -r reference.tif -o aligned.tif

  -i, --input arg      Source GeoTIFF to align
  -r, --reference arg  Reference GeoTIFF (ground truth, more accurate)
  -o, --output arg     Output aligned GeoTIFF (COG, reprojected to 
                       EPSG:3857)
  -m, --mode arg       similarity (default) | translation (default: 
                       similarity)
      --validate       Only validate inputs; do not align
      --no-seed        Disable phase-correlation seed (slower NCC search)
      --overwrite      Replace the output if it already exists
  -h, --help           Print help
      --debug          Show debug output

```

### gsplat

```
Convert a Gaussian Splat (.ply, .splat or .spz) to the compressed .spz format, or export the training data of a splat from an ODM project.
Usage:
  ddb gsplat input.{ply|splat|spz} [output.spz]
       gsplat --training-data <output folder> [--max-image-size <pixels>] [--max-points <count>] <ODM project folder> [args]

  -i, --input arg           Gaussian Splat file to convert (.ply, .splat or 
                            .spz), or with --training-data the ODM project 
                            folder
  -o, --output arg          Output .spz file (default: the input with the 
                            .spz extension; a .spz input needs another 
                            path)
      --training-data arg   Write the training data of a Gaussian splat 
                            from the outputs of an ODM project 
                            (cameras.json, odm_report/shots.geojson, 
                            images/, odm_georeferencing/coords.txt and its 
                            point cloud) into this folder, which must be 
                            new or empty and apart from the project: a 
                            COLMAP model (sparse/0), the images (images/) 
                            and georef.json, which makes a splat trained 
                            from it and put next to it georeferenced
      --max-image-size arg  With --training-data: longest side in pixels of 
                            the exported images (default: the originals)
      --max-points arg      With --training-data: most points of the sparse 
                            model (at most 10000000) (default: 100000)
      --overwrite           Replace the output if it already exists
  -h, --help                Print help
      --debug               Show debug output

```
