DroneDB has five ways in for code and scripts. They share one engine: the DroneDB library
(`libddb`) indexes the files, builds the streaming versions and answers the questions. Hub and
Registry use the same library on the server.

| Interface | What it is | Runs on | Use it to |
|---|---|---|---|
| [`ddb` CLI](/developers/cli/quick-start.mdx) | A command-line tool | Your computer | Index and check folders, build files offline, share, push and pull datasets, script batch jobs |
| [DroneDB library (C API)](/developers/library.mdx) | `libddb.so` / `ddb.dll` with the C header `ddb.h` | Your program | Put DroneDB inside an application in C, C++, .NET, Python or any language with a C FFI |
| [REST API](/developers/api/workflows.mdx) | The HTTP API of Registry (and of Hub) | A Registry server | Automate uploads, listings, builds and tasks; manage users and organizations; build your own front end |
| [STAC API](/developers/stac.mdx) | A SpatioTemporal Asset Catalog of the datasets | A Registry server | Find datasets and files with STAC tools (pystac, STAC Browser, QGIS) |
| [OGC services](/developers/ogc.mdx) | WMS, WFS, WMTS, WCS and OGC API per dataset | A Registry server | Show datasets in GIS software and web maps (QGIS, ArcGIS, OpenLayers, MapLibre) |

## Which one to use

- **You have files on a disk and want them on Hub.** Use `ddb share` or `ddb push`. See the
  [CLI quick start](/developers/cli/quick-start.mdx).
- **You run a nightly job or a pipeline.** Use the CLI for local work and the
  [REST API](/developers/api/workflows.mdx) for server work: uploads, builds, processing tasks.
- **You write a desktop or server application that reads drone data.** Load the
  [library](/developers/library.mdx). The CLI already contains it, so a command-line user does not need it.
- **You want the data in QGIS or a web map.** Use the [OGC services](/developers/ogc.mdx), or the direct
  COG and COPC links. Hub users can also start from the
  [QGIS guide](/docs/hub-guide/sharing/qgis).
- **You index many datasets in a catalog.** Use the [STAC API](/developers/stac.mdx).
- **You manage a self-hosted Registry.** See [Self-hosting](/docs/self-hosting), the
  [Users & organizations API](/developers/users-api.mdx) and the [Processing API](/developers/processing-api.mdx).
