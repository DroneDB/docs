## When to use it

Use the compare view to show up to six georasters of a dataset side by side, from any folder: the
flights of a site over a season, an orthophoto next to its elevation model. The address of the
page holds the whole comparison, so you can send it as a link. Users with write access save
comparisons in the dataset, where everyone who can open the dataset finds them.

## Steps

<Steps>

1. In the file list of a dataset, right-click a georaster and select **Compare to...**. Or select
   two to six georasters, right-click and select **Compare in Map**. The compare view opens in a
   new tab.

   <Screenshot id="analyse/compare-view--menu" />

2. With **Compare to...**, the **Add raster to compare** dialog opens. Go to any folder of the
   dataset and select another georaster.

   <Screenshot id="analyse/compare-view--picker" />

3. The map shows one band for each raster. Drag the dividers to swipe. Use **Move left**,
   **Move right** and **Remove from comparison** on the name of a raster.

   <Screenshot id="analyse/compare-view--bar" />

4. Click **Add raster** to add another raster. It goes to the right.

5. Click **Copy link** to copy the address of the comparison.

6. Users with write access click **Save** and type a **Name**. The comparison shows under the
   folder tree of the dataset, in **Comparisons**.

   <Screenshot id="analyse/compare-view--saved-list" />

</Steps>

## Options

### The compare bar

| Control | What it does |
|---|---|
| Name | The name of the saved comparison, or **Unsaved comparison**. **Unsaved changes** shows after a change. |
| **Add raster** | Adds a georaster from any folder of the dataset. |
| **Copy link** | Copies a link that opens the same comparison: the rasters, their order, opacity and Plant Health settings, the dividers, the view and the basemap. |
| **Save** | Saves the comparison in the dataset. The first time, it asks for a name. |
| **Save as new** | Saves a copy under a new name. |

The map of the compare view has the same tools as the
[Map tab](/hub-guide/analyse/compare-layers.mdx): opacity, layer order, Plant Health for each raster, the split
button and the basemap of **Map Settings**.

### Saved comparisons

Double-click a comparison under **Comparisons** to open it. Right-click it for these actions:

| Action | Who | What it does |
|---|---|---|
| **Open** | Everyone who can open the dataset | Opens the comparison in the compare view. |
| **Copy Link** | Everyone who can open the dataset | Copies a link to the saved comparison. |
| **Rename** | Users with write access | Changes the name. |
| **Delete** | Users with write access | Deletes the comparison. Its links stop working. The rasters are not deleted. |

## Limits & requirements

- A comparison has at most 6 georasters, all from the same dataset.
- A comparison that is too large for a link cannot be copied as a link. Save it, then share the
  link of the saved comparison.
- If a raster of a saved comparison is deleted or moved, the comparison keeps its place. Use
  **Pick another** to select a new file, or **Remove** to remove it.
- If someone saved the comparison after you opened it, **Save** asks whether to overwrite their
  changes or to save yours as a new comparison.
- The compare view does not load or save measurements.
