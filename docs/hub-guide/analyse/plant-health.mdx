## When to use it

Use Plant Health to see how healthy a crop or a field is. Hub computes a vegetation index from
the bands of the raster, for example NDVI from the red and near-infrared bands, and paints it with
a colormap. Nothing is processed in advance: you can change the index at any time.

## Steps

<Steps>

1. Open the multispectral orthophoto on the map. Click the **Plant Health** button (a leaf) next
   to the opacity slider. You can also right-click the file in the dataset and select
   **Plant Health**.

2. In the **Plant Health** panel, select a **Formula**, for example **Normalized Difference Vegetation
   Index** (NDVI). The list gives the full names; the table of indices below gives their short names.

   <Screenshot id="analyse/plant-health--ndvi" />

3. Select a **Colormap** and a **Stretch**. Drag the handles of the **Histogram** to set the range
   of values the colormap covers.

4. To learn what each index shows, click the information button next to **Formula**. The
   **Vegetation index formulas** dialog shows the formula, the bands it needs and when to use it.

   <Screenshot id="analyse/plant-health--formulas-dialog" />

5. Click **Copy Link** to copy a link that opens the map with the same **Formula**, **Colormap** and
   **Rescale** (a toast says **Link copied to the clipboard**), or **Export** to download the result as a
   GeoTIFF.

</Steps>

## Options

| Option | What it does | Default |
|---|---|---|
| **Preset** | A band combination or an index made for the camera that took the images. It shows when Hub knows the camera. | — |
| **Formula** | The vegetation index. **None (bands only)** shows the bands; see [Colormaps, bands & histogram](/hub-guide/analyse/colormaps.mdx). | None |
| **Colormap** | The colours of the index. | Red-Yellow-Green |
| **Stretch** | How Hub maps the values to the colours: **Percentile (2%-98%)**, **Min / Max**, **Std Dev (±2σ)** or **Custom**. | Percentile |
| **Rescale** | The minimum and the maximum value, for example `-1,1`. Empty: automatic. | Automatic |
| **Reset** | Puts all options back to their defaults. | — |
| **Original** | Shows the raster without the index. | — |

### Indices

| Bands | Indices |
|---|---|
| Red, green, blue | VARI, EXG, GLI, vNDVI |
| Near-infrared and visible bands | NDVI, NDWI, GNDVI, GRVI, ENDVI, ARVI, SAVI, OSAVI, EVI |
| Red edge, near-infrared | NDRE |
| Visible bands only | NDYI, MPRI |

The list shows every index, and **Celsius Temperature** and **Kelvin Temperature**, which are for
thermal rasters only (they have a ✗ on the others). An index that the raster cannot compute has a ✗. Its tooltip, and
the formulas dialog, give the reason:

- **A band is missing**: the message names the bands the index needs.
- **The raster is not reflectance**: SAVI, OSAVI and EVI need values from 0 to 1 (a
  floating-point raster). On 8-bit or 16-bit rasters they give wrong values, so Hub does not offer
  them. Use NDVI, NDRE or another ratio index on such rasters.

Hub reads the bands from the camera profile it matched to the file, so each index uses the right
band whatever the band order of the camera.

## Limits & requirements

- Plant Health needs a georaster with two or more data bands, or a GeoTIFF photo with a
  footprint. A raster with one band per file needs
  [Merge multispectral bands](/hub-guide/processing/merge-multispectral.mdx) first: the panel says
  **Single band image. Use Merge Multispectral to combine bands for vegetation indices.** The merge of
  the bands of a MicaSense, Sequoia or DJI capture keeps the camera data, so Plant Health opens the
  merged file.
- **Export** is greyed out when the server estimates the file (the pixels that have a value, 4 bytes each) as larger than its export limit; its tooltip gives the limit.
- The **Histogram** covers the range the index can have (NDVI: -1 to 1), narrowed to the values near
  the bulk of the data (within one spread of the 2nd to 98th percentiles). When some values are outside
  what it shows, a note under it says **Outliers: the values go from … to …** with the real lowest and
  highest values. If too few bars fit in the range, the histogram has no bars, but the handles still set
  the range.
- When the map shows two or more rasters, each raster with bands has its own leaf button in the
  layer opacity panel.
