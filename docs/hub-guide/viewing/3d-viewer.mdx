## When to use it

The 3D viewer is the viewer of 3D Tiles (`.3tz` archives). It also shows a 3D model, a point cloud, a georaster or a vector file in 3D, and it has measurement tools for all of them.

## Steps

<Steps>

1. Open a file in the 3D viewer:
   - Double-click a `.3tz` file. It opens in the 3D viewer.
   - For a model, a point cloud, a georaster or a vector file, right-click it and choose **Experimental** › **Unified Viewer**.

   The viewer opens in a new browser tab.

   <Screenshot id="viewing/3d-viewer--3d-tiles" />

2. Move around:
   - Drag with the left mouse button to rotate around the center of the view.
   - Drag with the right mouse button to pan.
   - Turn the mouse wheel to zoom to the pointer.
   - Double-click a point to center the view on it.
   - Click **Home** (bottom left), or press `Home` or `0`, to go back to the first view.

   <Screenshot id="viewing/3d-viewer--point-cloud" />

3. In the **Layers** panel (top right), clear a check box to hide a layer.

4. Use the toolbar (top left) to measure: **Measure point**, **Measure distance** and **Measure area**. Click **Clear measurements** to remove them. See [Measurements in 3D](../measure/3d.mdx).

5. Click **Display settings** (the gear, bottom right) to change the light.

</Steps>

## Options

| Option | What it does |
|---|---|
| **Ambient** | Light that falls on every side the same way |
| **Directional** | Light from one direction, which shows the shape |
| **Sky / ground fill** | Light from above and below, which fills the shadows |
| **Reset** | Sets the three values back to the defaults |

The lighting is a preference. You can also set it under **3D viewer lighting** on the **Viewers** tab of the [Preferences](../account/preferences.mdx).

## Local and geographic coordinates

| File | How it shows |
|---|---|
| 3D Tiles with a position | On a globe, with an OpenStreetMap basemap |
| 3D Tiles without a position, 3D model | Upright, in its own coordinates |
| Point cloud with a coordinate system | In that coordinate system, on a basemap |
| Georaster, vector file | On a basemap |
| Point cloud or CAD drawing (DXF, DWG) without a coordinate system | In its own coordinates, with a **Local coordinates** badge at the top. For a drawing the badge also shows its units |

To put a drawing on the map, [set its coordinate system](../files/coordinate-system.mdx).

## Limits & requirements

- The file opens after its build is done. A model needs its 3D Tiles, which the build makes next to the model. See [Builds](../processing/builds.mdx).
- The viewer needs a browser with WebGL.
- Measurements in this viewer are not saved: they go when you close the page. To save 3D measurements of a point cloud, use the [point cloud viewer](./point-cloud.mdx).
- Gaussian splats open in the [splat viewer](./splats.mdx), not here.

The viewer is built on Giro3D. A `.3tz` file is a ZIP with a `tileset.json` at its root; the build extracts it. A georeferenced tileset is placed on the Earth ellipsoid (EPSG:4978); the other files show in EPSG:3857 or in the CRS of the point cloud.
