## When to use it

Read the notes and the reports that come with a dataset without a download: a `README.md` with the licence and the story of a flight, or the PDF quality report that ODM writes for each project.

## Steps

<Steps>

1. In the file list, double-click a Markdown file (`.md`), or right-click it and choose **Open Markdown**. The file opens as a formatted page in a new browser tab.

2. To change the text, click **Edit** (the pencil button, top right). Edit the Markdown source, then click **Save**. You need write access to the dataset. See [Edit text & Markdown](/hub-guide/files/edit-text.mdx).

3. Double-click a PDF file, or right-click it and choose **Open PDF**. The PDF opens in a window over the page, in the PDF viewer of your browser.

   <Screenshot id="viewing/markdown-pdf--pdf" />

4. Use the toolbar of the browser's PDF viewer to zoom, search, print or save the file. Close the window to go back to the file list.

</Steps>

## Limits & requirements

- The PDF window uses the PDF viewer of the browser. Its toolbar changes from one browser to another.
- Links and images in a Markdown file show as in any Markdown page. Hub removes scripts and other unsafe content.
- The `README.md` of a dataset also shows on the dataset page. **Add Readme** in the dataset settings creates one. See [Create & configure a dataset](/hub-guide/datasets/create.mdx).
