## When to use it

Use the 3D model viewer to look at a textured mesh, for example the 3D model of a photogrammetry project. Hub streams the model: the coarse shape shows first and the detail loads where you look, so a model with many textures opens quickly.

## Steps

<Steps>

1. In the file list, double-click a 3D model, or right-click it and choose **Open 3D Model**. The viewer opens in a new browser tab.

   <Screenshot id="viewing/3d-model--overview" />

2. Move around the model:
   - Drag with the left mouse button to rotate.
   - Drag with the right mouse button to pan.
   - Turn the mouse wheel to zoom.

3. Use the toolbar at the bottom right. **Home** (or the `H`, `0` or `Home` key) goes back to the first view of the model. **Fullscreen** fills the screen. The question mark opens **Controls**, a list of the gestures of the mouse and of the touch screen.

4. Click the **Lighting** button (the gear, bottom left) to change the light. The settings open in a panel beside the button. Move the **Ambient** and **Directional** sliders. A model without a texture also has **Shininess**. Click **Reset** to go back to the defaults.

   <Screenshot id="viewing/3d-model--lighting" />

</Steps>

## Options

| Option | What it does |
|---|---|
| **Ambient** | Light that falls on every side of the model the same way |
| **Directional** | Light from one direction, which shows the shape |
| **Shininess** | How shiny a model without a texture looks |
| **Reset** | Sets the three values back to the defaults |

The lighting is a preference: it applies to every model you open. You can also set it on the **Viewers** tab of the [Preferences](/hub-guide/account/preferences.mdx).

## Models built before Registry 3.0

Registry 3.0 builds 3D models in a new format. A model that an earlier version built opens in the previous viewer until Hub rebuilds it in the new format. The rebuild runs in the background and needs nothing from you. The lighting settings are the same in both viewers.

## Limits & requirements

- The model opens after its build is done. See [Builds](/hub-guide/processing/builds.mdx). An OBJ needs its `.mtl` file and its textures in the same folder. When the `.mtl` is missing, the build waits until you upload it.
- The viewer needs a browser with WebGL. On a high-DPI screen it draws at the pixel ratio of the screen, up to 2x.
- The viewer has no measurement tools. To measure a model, open it in the [3D viewer](/hub-guide/viewing/3d-viewer.mdx).
