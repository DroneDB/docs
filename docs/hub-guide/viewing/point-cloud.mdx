## When to use it

Use the point cloud viewer to look at a point cloud in 3D, change how its points are coloured and measure it. Hub streams the points: it loads the coarse points first and adds detail where you look, so a large cloud opens quickly.

## Steps

<Steps>

1. In the file list, double-click a point cloud, or right-click it and choose **Open Point Cloud**. The viewer opens in a new browser tab.

   <Screenshot id="viewing/point-cloud--overview" />

2. Move around the cloud:
   - Drag with the left mouse button to orbit.
   - Drag with the right mouse button to pan.
   - Turn the mouse wheel to zoom.
   - Double-click a point to fly to it.

3. Use the tool panel over the view. It has labelled buttons (icons only on a phone): the measuring tools **Point**, **Distance**, **Height** and **Area**, **Clip volume** and **Remove clips**, the views **Top**, **Front**, **Left** and **Right**, and **Colour by**. The menu button (top right) opens the side menu, for the advanced settings. Its sections are **Appearance**, **Tools**, **Scene**, **Filters** and **About**. It follows what you do in the tool panel.

   <Screenshot id="viewing/point-cloud--menu" />

4. To colour the points, choose a value in **Colour by**: **Colour**, **Elevation**, **Intensity**, **Classification** or **Return number**. The list offers an attribute when the file has it (it can take a moment while the first points load). For other attributes, open **Scene**, click the point cloud in the tree and use **Attribute**.

   <Screenshot id="viewing/point-cloud--attribute" />

5. To look at the cloud from a side, click **Top**, **Front**, **Left** or **Right**. To keep only the points inside a box, click **Clip volume**, then click to place the box (`Esc` or **Cancel** stops placing it). **Remove clips** removes the boxes. To change the navigation, open **Tools** in the side menu. Under **Navigation**, choose orbit, fly, helicopter or earth controls.

6. To measure, click **Point**, **Distance**, **Height** or **Area** in the tool panel. Click the points; double-click, right-click or press `Enter` to finish, and `Esc` to cancel. For the other tools (angle, circle, volume), open **Tools** in the side menu. See [Measurements in 3D](/hub-guide/measure/3d.mdx). **Undo** (`Ctrl+Z`) and **Redo** (`Ctrl+Y`), at the top left, undo and redo adding and deleting a measurement.

</Steps>

## Options

| Option | Where | What it does |
|---|---|---|
| **Units** | Top left | **Metric (m)** or **Imperial (ft)** for the measurements. The map uses the same setting |
| **Point budget** | **Appearance** | The most points drawn at one time. A lower value is faster |
| **Field of view** | **Appearance** | The angle of the camera |
| **Eye-Dome-Lighting** | **Appearance** | Shading that makes the shape of the points easier to see. Off when the viewer opens |
| **Point size**, **Opacity** | **Scene**, point cloud | The size and the transparency of the points |
| **Colour by** | Tool panel | How the points are coloured: **Colour**, **Elevation**, **Intensity**, **Classification** or **Return number** |
| **Attribute** | **Scene**, point cloud | The same, with every attribute of the file |
| **Clip volume**, **Remove clips** | Tool panel | Shows only the points inside a box that you place, and removes the boxes |
| **Top**, **Front**, **Left**, **Right** | Tool panel | Looks at the point cloud from that side |
| **Clipping** | **Tools** | Shows only the points inside or outside a box or a polygon |
| **Classification**, **Returns** | **Filters** | Shows or hides the classes and the returns of a LiDAR cloud |

## Limits & requirements

- The point cloud opens after its build is done. Until then the viewer says that the file is still being processed. See [Builds](/hub-guide/processing/builds.mdx).
- The viewer needs a browser with WebGL. On phones and tablets it draws fewer points.
- On a high-DPI screen the viewer draws at the pixel ratio of the screen, up to 2x. A point keeps its size on the screen, and the lines and labels of the measurements grow with the window, from 12 to 18 px for the labels, so they stay readable on a large screen.
- Everyone who can read the dataset can measure. To save measurements you need write access.
