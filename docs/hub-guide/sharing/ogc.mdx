## When to use it

GIS programs and web maps speak the OGC standards. Every dataset of Hub offers them for its georasters and
vectors. Copy a service URL from the Share dialog and add it to QGIS, ArcGIS Pro, GeoServer, OpenLayers or
any other OGC client.

## Steps

<Steps>

1. Right-click a file or a folder and click **Share/Embed**. For a folder, the window is **Share Folder**.

2. Open the **Share** list. The services are under **OGC services**. A service that the file cannot offer
   shows **(n/a)**.

3. Select a service. The window shows its URLs. Click the copy button of the URL you need, usually the
   **GetCapabilities URL**.

4. Click the question mark next to the list (**How to use this service**). The window shows what the service
   returns and the steps for QGIS, ArcGIS Pro and GDAL, with your URL.

   <Screenshot id="sharing/ogc--hints" />

5. Follow the steps in your program.

</Steps>

## Services

| Service | Gives | For |
|---|---|---|
| **WMS (Web Map Service)** | Map images, rendered by the server | Georasters and vectors |
| **WMTS (Web Map Tile Service)** | Ready-made map tiles | Georasters and vectors |
| **WFS (Web Feature Service)** | The vector features themselves | Vectors only |
| **WCS (Web Coverage Service)** | The raster values, for example as GeoTIFF | Georasters only |
| **OGC API Features** | Vector features as JSON (GeoJSON) | Vectors, from a file (not from a folder) |
| **OGC API Tiles** | Tiles, through the newer OGC API | Georasters and vectors, from a file (not from a folder) |

The window shows the URLs that the service has, for example **GetCapabilities URL**, **Landing page**,
**Collections**, **RESTful tile template**, **GetMap (sample)**, **GetFeature (sample)** or **GetCoverage
(sample)**. A *sample* URL is an example request. Replace its placeholders, such as the bounding box of
GetMap, before you use it.

For a multispectral raster, WMS also offers index styles such as NDVI, when the bands allow them.

## Limits & requirements

- Only georasters and vectors can be shared through OGC services. Other files show **Not supported**.
- Share a folder to get one service for all the georasters and vectors in it.
- For a private dataset, the window shows **Allow access to anyone with the link**. The button makes the whole
  dataset **Unlisted** (see [Visibility](/hub-guide/sharing/visibility.mdx)). Programs can also sign in with your user name and
  password (Basic authentication).

