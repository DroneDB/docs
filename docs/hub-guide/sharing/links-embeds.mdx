## When to use it

Send a colleague a link that opens an orthophoto, a point cloud or a 3D model straight in its viewer. Or put
the viewer in a web page, a blog or a project report, so that readers can pan and zoom without leaving it.
The embed above is a live Hub viewer.

## Steps

<Steps>

1. In the file browser, right-click the file and click **Share/Embed**. You can also select one file and
   click the share button in the header, or **Share/Embed** in the details panel.

   <Screenshot id="sharing/links-embeds--menu" />

2. The **Share / Embed** window opens with **Share: Link**. Click the copy button next to **Share link**.
   The link opens the file in its default viewer. To hide the Hub around it, check **Viewer only**.

   <Screenshot id="sharing/links-embeds--link" />

3. To embed the viewer, select **Share: Embed**. Click the code, or the copy button, to copy it.

   <Screenshot id="sharing/links-embeds--embed-code" />

4. Paste the code into the HTML of your page.

</Steps>

## Share modes

| Mode | What you get |
|---|---|
| **Link** | The address of the file in its viewer, with the option **Viewer only**. For a file without a viewer: a link that opens the file in the browser |
| **Embed** | An `<iframe>` of the viewer, 600 × 400 pixels, that can go full screen |
| **TMS (Tile Map Service)** | A tile URL for other map programs. See [Open Hub data in QGIS](/hub-guide/sharing/qgis.mdx) |
| **QGIS** | The direct link of the built file. See [Open Hub data in QGIS](/hub-guide/sharing/qgis.mdx) |
| WMS, WMTS, WFS, WCS, OGC API | Service URLs. See [OGC services](/hub-guide/sharing/ogc.mdx) |

## The embed code

The code looks like this. Change `width` and `height` to fit your page:

```html
<iframe frameborder="0" width="600" height="400" allowfullscreen
        allow="fullscreen" src="https://hub.dronedb.app/r/…/map?embed=1"></iframe>
```

- Keep `?embed=1` at the end of the address. Without it, the browser does not show the Hub inside another
  site.
- In an embed, the Hub hides its header, the back arrow and the buttons that add or remove layers, as
  with [Viewer only](#viewer-only): only the viewer shows.
- Copy the code from the window, do not write the address by hand: the path of the file is encoded in it.

## Viewer only

**Viewer only** is off when the window opens. Check it, and the link has `embed=1`: the Hub hides its
header and the back arrow. The window says: *Hides the Hub header, the back button and the buttons that
add or remove layers. Anyone with the link can still open the rest of the dataset.*

People who open a viewer-only link see the layers of the link. They can hide them or change their
opacity, but they cannot add or remove layers.

## Copy link on the map

The Share window does not include the layers you added to a map. Save them in a view, then use **Copy
link** in the toolbar of the map.

<Steps>

1. Open the file on the map. Add layers with **Add layer**. A user with write access clicks **Save** and
   types a name (see [Map views & saved views](/hub-guide/viewing/map-views.mdx)).

2. Click **Copy link**. For a saved view, the panel shows its link. It opens the layers, their order
   and opacity, the split, the position and the basemap you saved.

3. Optional: check **Viewer only**. Click the copy button.

   <Screenshot id="sharing/links-embeds--copy-link" />

</Steps>

A link never holds changes you have not saved. If the view has them, the panel gives the link of the
saved view, or of the file, and says **Save the view to share your changes.** Users with write access
click **Save** in the panel.

## Limits & requirements

- A link or an embed works for others only when the dataset is **Public** or **Unlisted**. For a private
  dataset, the window says that only its members can open the links, and shows **Make the dataset
  Unlisted...**. Hub asks first: the whole dataset becomes **Unlisted** (see
  [Visibility](/hub-guide/sharing/visibility.mdx)). On the map, the **Copy link** panel says that only
  people with access to the dataset can open the link.
- You share one file or one folder at a time; there is no share of a whole dataset. Link and Embed are
  for one file. A folder offers the [OGC services](/hub-guide/sharing/ogc.mdx) only.
- A viewer loads the data of the file. A large point cloud or model in an embed can be slow on a phone.
