## When to use it

You styled a raster in the Plant Health panel, for example an NDVI map with a colormap or a false-colour band
combination. You want that result as a file for a report or for a GIS program. Export writes it as a GeoTIFF
and your browser downloads it.

## Steps

<Steps>

1. Open the raster on the map.

2. Click **Plant Health** in the layer controls.

3. Set the view: a **Preset**, a **Formula**, the **Bands (R,G,B)**, the **Colormap**, the **Stretch** or the
   **Rescale** range. See [Plant health](/hub-guide/analyse/plant-health.mdx) for each control.

   <Screenshot id="processing/export-raster--formula" />

4. Click **Export**. The button turns into a spinner while Hub makes the file.

5. Your browser downloads `<name>_export.tif`.

</Steps>

## What the file holds

| Your settings | The exported GeoTIFF |
|---|---|
| A **Preset** | The bands of the preset |
| **Bands (R,G,B)**, no formula | The three bands you selected |
| A **Formula** | The index, with the **Colormap** and the **Rescale** range you set |

The export runs as a task on the server: **Export raster (GeoTIFF)** in the [Tasks tab](/hub-guide/processing/tasks.mdx). There
you can download the result again until it expires.

## Limits & requirements

- Read access is enough: you can export from any public dataset.
- Plant Health, and so Export, is available for rasters with two data bands or more. Single-band rasters
  (DEMs, thermal mosaics) do not offer Export.
- The server limits the size of an export. When the estimated file is too large, **Export** is grey and its
  tooltip gives the limit.
