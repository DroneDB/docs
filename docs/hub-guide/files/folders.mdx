## When to use it

Keep the files of a dataset in order: one folder per flight or per product, clear names, no
files that you do not need.

## Steps

<Steps>

1. To create a folder, open the parent folder and click **New folder** in the toolbar. You can
   also right-click and click **New folder**. Type the **Folder name** and click **Create folder**.

   <Screenshot id="files/folders--new-folder" />

2. To move files, select them and drag them onto a folder. You can drag from the list to the tree,
   and from the tree to the list. Hub highlights the folder that gets the files.
3. To rename a file or a folder, select it and click **Rename** in the toolbar, or right-click it and
   click **Rename**. Type the new name and click **Rename**.
4. If the file has sidecar files, such as `ortho_measurements.geojson` next to `ortho.tif`, keep
   **Also rename sidecar files** selected. Hub then renames them with the file.
5. To delete, select the files and folders, then click **Delete** in the toolbar, press Delete
   (the delete key on a Mac), or right-click and click **Delete**. Click **Delete** to confirm.

   <Screenshot id="files/folders--delete-confirm" />

</Steps>

## Options

| Option | What it does | Default |
|---|---|---|
| **Also rename sidecar files** | Renames the files named `<name>_<suffix>` next to the file, for example its saved measurements or the cameras of a splat | On |

## What happens

- A move or a rename keeps the builds of a file: Hub does not build it again. A rename that gives
  a file a type that Hub builds (for example `.tif`) starts a build.
- Renaming the root of the tree renames the dataset. Its slug and its address change, and the page
  opens at the new address.
- A delete removes the files from the dataset. If some files cannot be deleted,
  a window lists them with the reason.

## Limits & requirements

- A name cannot contain `/`, `\` or `..`, and cannot start with `.`.
- You cannot move a folder into itself or into one of its subfolders.
- To move files to another dataset, use [Copy, cut, paste & transfer](/hub-guide/files/copy-paste.mdx).
- You cannot undo a delete.
- **Rename** and **Delete** stay in the toolbar when they do not apply. They are dimmed, and their
  tooltip says why, for example "Select one file to rename". The dataset itself cannot be deleted
  from the file list.
