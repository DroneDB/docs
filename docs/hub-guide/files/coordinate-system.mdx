## When to use it

Most CAD drawings do not say which coordinate system their coordinates are in. Without one, Hub
cannot place the drawing on the map. It shows the drawing in the 3D viewer, in local drawing
coordinates. If you know the coordinate system of the drawing, set it once, and Hub places the
drawing on the map.

## Steps

<Steps>

1. Click the drawing and read the **Coordinate system** row of its properties. **None: local drawing
   coordinates** means that the drawing has no coordinate system.

   <Screenshot id="files/coordinate-system--properties" />

2. Right-click the drawing and click **Tools** › **Set Coordinate System**.
3. Select **Coordinate system** and type an EPSG code (`EPSG:32632`, or only `32632`) or a WKT
   definition. To keep the drawing off the map, select **Local drawing coordinates (not placed on
   the map)**.
4. Click **Apply**. Hub checks the form of what you typed first and says under the field what to enter:
   a number or `EPSG:` and a number, or a WKT definition that starts with `PROJCS`, `GEOGCS`, `PROJCRS` or
   `GEOGCRS`. Whether the code exists is for the server to say: its answer shows under the same field. Then Hub
   saves the coordinate system and builds the drawing again.

</Steps>

## Where the coordinate system comes from

DroneDB looks for a coordinate system in this order. The **Coordinate system** row tells which one
it used.

| Source | Row shows |
|---|---|
| A `.prj` file with the same name next to the drawing (`site.dwg` and `site.prj`) | `… (from the .prj file)` |
| The geographic location that AutoCAD or Civil 3D stored in the drawing | `… (stored in the drawing)` |
| A DXF only: coordinates that fit longitude and latitude | `WGS84 (EPSG:4326), assumed` |
| None of these | `None: local drawing coordinates` and the units of the drawing |

## What happens

- **Apply** writes `<drawing name>.prj` next to the drawing. Other GIS software reads this file too.
  An upload of a `.prj` file with the same name does the same.
- To use the coordinate system of the drawing again, delete the `.prj` file.
- A drawing in local coordinates opens in the [3D viewer](/hub-guide/viewing/3d-viewer.mdx) without a globe,
  with its units, for example **Local coordinates (m)**.

## Limits & requirements

- DWG files from AutoCAD R13 to R2018 (AutoCAD 2018 and later save as R2018). A DWG needs the LibreDWG
  converter (`dwg2dxf`) on the server. Without it the build fails with **DWG support needs dwg2dxf
  (LibreDWG)**: ask the administrator, or export the drawing as DXF from your CAD software and upload the
  DXF. If a DWG does not convert for another reason, do the same.
- 3D solids are not converted. A drawing that has only 3D solids shows nothing.
- A drawing without a coordinate system is not on the map and not in the OGC services (WMS, WFS,
  WMTS, OGC API).
