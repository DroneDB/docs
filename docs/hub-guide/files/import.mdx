## When to use it

Import when the data is already on a web server or on another Hub. The server downloads it, so
your computer and your connection are not used. This is fast for large files.

## Import one file from a URL

<Steps>

1. Open the destination folder in the dataset.
2. Click **Upload** in the toolbar, then **Import from URL**. You can also copy a URL and press
   Ctrl+V on the file list: the same window opens with the URL in it.
3. Type the **File URL** and click **Verify**. Hub shows if the URL is reachable, the size of the file,
   and if its type or size is not allowed.
4. Change the **File name** and the **Destination folder** if necessary. Select **Overwrite existing
   file** to replace a file with the same name.
5. If the server asks for a user name and a password, open **Authentication (optional)** and type
   them.
6. Click **Import**. The window shows the progress. You can close it: the import continues in the
   **Tasks** tab.

</Steps>

## Make a dataset from another Registry or an archive

<Steps>

1. Open the datasets page of the organization and click **Import Dataset**.
2. Select the **Source**:
   - **DroneDB Registry / Hub**: type the **Registry URL**, for example `https://hub.dronedb.app`.
     For a private dataset, open **Credentials (optional)** and type the **Username** and the **Password** of
     an account on that server. The credentials fold again when they are empty, and open by themselves when **Verify** fails.
     Click **Browse organizations** and **Browse datasets** to select the **Organization** and the
     **Dataset**, or type their slugs. Each list has a search field (**Search organizations**, **Search
     datasets**), so a long list is not scrolled.
   - **Archive URL**: type the **Archive URL** of a ZIP, TAR, 7z or RAR file, and an optional user name
     and password. **Verify** refuses a web page with "The file is not a ZIP, TAR, 7z or RAR archive".
     It also works with a server that refuses a check of the headers.
3. Click **Verify**. Hub shows the number of files and the size, scrolls to the next step and puts the
   cursor in the dataset name. **Import** stays at the bottom of the window, in view.

   <Screenshot id="files/import--dataset-dialog" />

4. Type the **Dataset Name**, select the **Visibility** and check the **Slug**.
5. Click **Import**. Click **Run in background** to close the window while the import runs. Follow the
   import in the **Tasks** tab of the new dataset. Click **Cancel** there to stop it.

While the import runs, the dataset is not shown as empty. Its row in the list of the organization has the
tag **Importing… 40 %**, and the dataset page has a banner **Importing… 40 % — the files appear here when the
import ends.** with a **View in Tasks** button. The folder does not say that it is empty meanwhile. When the
import ends, the list of files loads by itself. A notice tells you when an import that runs in the background
ends, wherever you are in Hub: **Import complete** with an **Open dataset** button, **Import failed** with the
reason of the task (and **Open dataset** only while the dataset still exists, because a failed or cancelled
import deletes the dataset it created), or **Import cancelled**.

</Steps>

## What happens

- The imported files are indexed and built like uploaded files.
- An archive from an **Archive URL** is extracted into the new dataset.
- Hub keeps the password of the source only for the import, encrypted.
- If you cancel an import, or it fails, Hub deletes the files that the import added. This is also
  true for **Import from URL**. The files that were in the dataset before, and the files that other
  users add meanwhile, stay. The confirmation of **Cancel** says what is deleted.
- A dataset that the import created is deleted a few minutes later if it is still empty.
- A failed import shows its reason as the error of the task in the **Tasks** tab.
- If the server restarts during an import, Hub rolls it back in the same way.

## Limits & requirements

- Only `http` and `https` URLs. The server refuses addresses of private and local networks.
- The server administrator sets the largest file and import size, and can block some file types.
- **Import Dataset** needs write access to the organization. **Import from URL** needs write access
  to the dataset.
