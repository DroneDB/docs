## When to use it

Rescan a dataset after a DroneDB upgrade that reads more from some files, or when the
metadata of files looks wrong: a missing GPS position, a wrong time, a missing thumbnail, a
file with the wrong entry type.

Rescan only the files that look wrong when you can: the rest of the dataset stays open, and it
takes the time of those files only. Rescan the whole dataset after an upgrade.

## Rescan some files or folders

<Steps>

1. In the file explorer, select the files and folders to rescan. A folder rescans every file inside it.
2. Right-click the selection and choose **Tools → Rescan**.
3. Read the list of what is rescanned and click **Rescan**.
4. The rescan runs as a task: follow it in the **Tasks** tab. The dataset stays open while it runs.
   When it ends, the explorer shows the files with their new metadata.

</Steps>

## Rescan the whole dataset

<Steps>

1. Open the dataset and click **Settings** (the wrench button at the top right).
2. Under **Maintenance**, click **Rescan Dataset**.

   <Screenshot id="files/rescan--settings" />

3. Read the side effects and click **Rescan**.
4. The dataset closes until the rescan ends: the page says **This dataset is being rescanned** with the
   progress. Click **Cancel rescan** to stop it, or **Back to datasets**. In the list of the organization,
   the row has the tag **Rescanning… 40 %**.

</Steps>

## What happens

- DroneDB reads each file again and replaces its metadata (GPS position, time, type and the
  other properties) with the new values.
- When the rescan ends, Hub starts a build of each rescanned file that can be built. A rescan of the
  whole dataset first deletes the cached thumbnails, tiles and built files of the dataset, then starts
  one build of the whole dataset.
- The builds are tasks of their own. In the **Tasks** tab they show under the rescan. A build that fails
  shows as a failed build: the rescan itself still succeeded.
- Until a file is built again, its viewers are not available.
- While a rescan of the whole dataset runs, nobody can open, edit, upload to or share the dataset. It
  can only be deleted: the delete stops the rescan first. When the rescan ends, the dataset opens again
  by itself, while its builds run.
- A rescan of some files leaves the dataset open. A file that is uploaded again or deleted while it is
  rescanned keeps what the upload or the delete did.

## Limits & requirements

- A rescan of a large dataset can take a long time.
- **Tools → Rescan** is not available while the whole dataset is being rescanned or imported.
- To rescan only some entry types or file extensions of the whole dataset, use the CLI or the API (below).
- A server administrator can rescan the matching files of every dataset with one API request, for
  example all DWG and DXF drawings after an upgrade. See [Upgrading](/docs/self-hosting/upgrading).
