## When to use it

The page of a dataset: its folders and files, every viewer and every file action.

## The page

<Screenshot id="files/browser--grid" />

- **Folder tree** (left): drag its border to change its width.
- **Files** tab: the folder selected in the tree, under the toolbar. The **Folder path** above the
  list goes back to a parent folder.
- **Detail panel** (right): a preview of the selected file, its
  [properties](/hub-guide/files/properties.mdx), **Open**, **Share/Embed** and **Build**.
- **Map** tab: the files that have coordinates on a map. See [Map viewer](/hub-guide/viewing/map.mdx).
- **Tasks** tab: the tasks of the dataset. See [Tasks panel & logs](/hub-guide/processing/tasks.mdx).

On a phone, the tree, the files and the properties are the tabs **Browser**, **Files** and
**Properties**.

## Steps

<Steps>

1. Click a folder in the tree. The **Files** tab shows its content as a grid of thumbnails.
2. Click **List** in the toolbar to see the files as rows. Click **Name**, **Type**, **Size**
   or **Modified** to sort. **Thumbnails** switches the list between thumbnails and small icons.

   <Screenshot id="files/browser--table" />

3. To find a file in any folder, type in **Search files** above the tree and press Enter (`*` is a
   wildcard, as in `*.json`). Hub says how many results it found, for example **3 results for "*.json"**,
   or **No files found**. **Clear search**, or Esc, goes back to the tree.

   <Screenshot id="files/browser--search" />

4. A folder with no files says **This folder is empty**. If you can write, it has **Upload** and **Import from
   URL** buttons.
5. Double-click a file, or select it and press Enter, to open it.
6. Right-click a file or a folder for its actions, in groups, with **Delete** last in red.
   Right-click an empty area for the folder's actions: **New folder**, **Upload**, **Paste**,
   **Select all** and **Refresh**.

   <Screenshot id="files/browser--context-menu" />

</Steps>

## What opens a file

| File | Double-click opens |
|---|---|
| Folder | The folder |
| Orthophoto, elevation model, vector | The [map viewer](/hub-guide/viewing/map.mdx), in a new tab |
| Point cloud, 3D model, 3D Tiles, splat, panorama | Its viewer, in a new tab |
| Markdown | The [Markdown viewer](/hub-guide/viewing/markdown-pdf.mdx) |
| Text, JSON, CSV | The [text editor](/hub-guide/files/edit-text.mdx) |
| PDF | The PDF viewer |
| Photo, video | A lightbox |
| ZIP or other archive | **Extract Archive**, if you can write. See [Extract archives](/hub-guide/files/archives.mdx) |

**Open** in the toolbar and the context menu does the same, and names the viewer, for example **Open Map**.

## The toolbar

The toolbar keeps the same buttons: **Upload**, **New folder**, **Open**, **Share/Embed**,
**Rename**, **Delete**, **Select all**, **Clear selection**, **Refresh**, **Grid**, **List** and
**Thumbnails**. A button that does not apply to the selection is dimmed, and its tooltip says why.
On a narrow screen, the buttons that do not fit go into **More** (⋮).

## Selection and keys

| Action | What it does |
|---|---|
| Click | Selects one file |
| Ctrl+click (Cmd+click on a Mac) | Adds or removes a file |
| Shift+click | Selects a range |
| **Select all** / **Clear selection** | Selects all the files of the folder, or none |
| Esc | Clears the selection |
| Tab | Moves the focus to the file list (the grid or the list is one stop), and out of it |
| Arrow keys (list) | Move the focus in the grid or the list; Home and End go to the first and the last item, Page Up and Page Down move by several rows. The item that has the focus is selected |
| Shift+arrow keys | Extend the selection |
| Ctrl+arrow keys (Cmd on a Mac) | Move the focus without changing the selection |
| Space / Enter | Toggles the selection of / opens the item that has the focus |
| Ctrl+A (Cmd+A on a Mac) | Selects all the files of the folder, when the focus is on the page or the list |
| F2 | Renames the one selected item |
| Arrow keys (tree) | Move in the tree, expand or collapse a folder |
| Ctrl+C, Ctrl+X, Ctrl+V | Copy, cut, paste. See [Copy, cut, paste & transfer](/hub-guide/files/copy-paste.mdx) |
| Delete (the delete key on a Mac) | Deletes the selection, after a question |

A selected tile has a tint, an outline and a check mark; a selected row has a bar on its left. The context
menu shows these keys next to **Copy**, **Cut**, **Paste** and **Delete**.

When you select several items, the detail panel shows a summary instead of one file: **4 items selected —
9.3 MB**, the types, the first five names and "and N more", with **Download** and **Delete**. The size
counts the files you selected; it does not count what is inside a selected folder.

## Options

| Option | What it does | Default |
|---|---|---|
| **Grid** / **List** | The layout of the **Files** tab | Grid |
| **Thumbnails** | Thumbnails and relative times in the list | On |
| Sort button next to **Search files** | Sorts the tree A→Z or Z→A, folders first | A→Z |

Hub saves the view to your account ([Preferences](/hub-guide/account/preferences.mdx)).

## Limits & requirements

- Read access shows the files; every change (upload, new folder, rename, delete...) needs write access.
- In a folder of 200 files or more, Hub draws only the rows on the screen.
- Saved map views show under the tree, in **Views**. See [Map views & saved views](/hub-guide/viewing/map-views.mdx).
