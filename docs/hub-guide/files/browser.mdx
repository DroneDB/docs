## When to use it

The file browser is the page of a dataset. It shows the folders and files, and starts every viewer
and every file action.

## The page

<Screenshot id="files/browser--grid" />

- **Folder tree** (left): the folders and files of the dataset. Drag the border to change its width.
  Hub keeps the width on this device.
- **Files** tab: the content of the folder that you selected in the tree. The **Folder path** above
  the list goes back to a parent folder.
- **Detail panel** (right): opens when you select a file. It shows a preview, the
  [properties](./properties.mdx) and the buttons **Open**, **Share/Embed** and **Build**.
- **Map** tab: the files that have coordinates on a map. See [Map viewer](../viewing/map.mdx).
- **Tasks** tab: the tasks of the dataset. See [Tasks panel & logs](../processing/tasks.mdx).

On a phone, the tree, the files and the properties are the tabs **Browser**, **Files** and
**Properties**.

## Steps

<Steps>

1. Click a folder in the tree. The **Files** tab shows its content as a grid of thumbnails.
2. Click **Table View** in the toolbar to see the files as rows. Click **Name**, **Type**, **Size**
   or **Modified** to sort.

   <Screenshot id="files/browser--table" />

3. In the table view, click **Expanded Table View** to switch between thumbnails with relative times
   and small icons with dates.
4. To find a file in any folder, type in **Search files** above the tree and press Enter. Use `*` as
   a wildcard, for example `*.json`. Click **Clear search** to go back to the tree.

   <Screenshot id="files/browser--search" />

5. Double-click a file, or select it and press Enter, to open it.
6. Right-click a file or a folder to see all the actions for it.

   <Screenshot id="files/browser--context-menu" />

</Steps>

## What opens a file

| File | Double-click opens |
|---|---|
| Folder | The folder |
| Orthophoto, elevation model, vector | The [map viewer](../viewing/map.mdx), in a new tab |
| Point cloud, 3D model, splat, panorama | Its viewer, in a new tab. A file that is not built yet shows why |
| Markdown | The [Markdown viewer](../viewing/markdown-pdf.mdx) |
| Text, JSON, CSV | The [text editor](./edit-text.mdx) |
| PDF | The PDF viewer |
| Photo, video | A lightbox |
| ZIP or other archive | **Extract Archive**, if you can write. See [Extract archives](./archives.mdx) |

The **Open** item of the context menu opens the selected files in the same way.

## Selection and keys

| Action | What it does |
|---|---|
| Click | Selects one file |
| Ctrl+click (Cmd+click on a Mac) | Adds a file to the selection, or removes it |
| Shift+click | Selects a range |
| **Select All** / **Deselect All** (toolbar), **Select All/None** (menu) | Selects all the files of the folder, or none |
| Esc | Clears the selection |
| Space / Enter | Selects / opens the file that has the focus |
| Up / Down arrows (tree) | Moves in the tree |
| Right / Left arrows (tree) | Expands or collapses a folder |
| Ctrl+C, Ctrl+X, Ctrl+V | Copy, cut, paste. See [Copy, cut, paste & transfer](./copy-paste.mdx) |
| Delete | Deletes the selection, after a question |

## Options

| Option | What it does | Default |
|---|---|---|
| **Grid View** / **Table View** | The layout of the **Files** tab | Grid |
| **Expanded Table View** | Thumbnails and relative times in the table | On |
| Sort button next to **Search files** | Sorts the tree A→Z or Z→A, folders first | A→Z |

Hub saves the view to your account. Set the default in [Preferences](../account/preferences.mdx).

## Limits & requirements

- Read access shows the files. Upload, rename, delete and the other changes need write access.
- In a folder of 200 files or more, Hub draws only the rows on the screen, so large folders stay fast.
- Saved comparisons show under the tree. See [Compare view & saved comparisons](../analyse/compare-view.mdx).
