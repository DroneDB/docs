## When to use it

Use the measure tools to get a length, an area or the position of a point from an orthophoto or
from any other data on the map. Anyone who can open the map can measure. Users with write access
save the measurements in the dataset, so the next visitor sees them too.

## Steps

<Steps>

1. Open an orthophoto on the map, or open the **Map** tab of a dataset. The measure toolbar is on
   the map. On a phone, and in a map less than 576 px wide or 560 px high, the tools are behind one
   **Measure** button: click it to open them. Closing it ends the tool that is active. Saved measurements of the file show automatically.

   <Screenshot id="measure/map--toolbar" />

2. Click **Measure Length**. Click the points of the line on the map. Double-click, right-click or press
   `Enter` to finish. Press `Esc` to cancel: the half-drawn line is removed. A hint on the map says the same
   for each tool.

3. Click **Measure Area**. Click the corners of the area (three or more) and finish the same way. The area
   shows in the middle of the polygon.

   <Screenshot id="measure/map--area" />

4. Double-click a measurement to open its properties. Give it a name and a description, change
   its colours, its line width and its fill opacity, or put it in a group. Click **Save**.

   <Screenshot id="measure/map--properties" />

5. Click **Measurement List** to see all the measurements. The list shows the numbered annotations by
   reference, then the other measurements by name. Type in the search box to find a measurement by
   name or by reference, and use the **Type**, **Category** and **Status** filters to show fewer rows.
   Click **New group** to make a group with a name and a colour. The eye button of a group hides or
   shows its measurements. The buttons of a row show when you point at it and also when you move the
   keyboard focus to it with `Tab`. A line under the list says **Saved in** and the path of the file
   that holds the measurements. When an elevation model is on the map, a stockpile has one more
   button, which opens [Stockpile Volume](/hub-guide/analyse/stockpile.mdx) on that pile.

   To work on many measurements at once, select them (see
   [Select measurements in the list](#select-measurements-in-the-list)). A bar under the list shows
   how many you selected and their total length, area and pile volume. From the bar:

   - **Move to** puts them in a group, or takes them out of their groups (**Ungrouped**).
   - **Show on map** closes the list and zooms the map to them. They stay highlighted until you click
     the map.
   - **Export** downloads only them, as GeoJSON or CSV.
   - **Delete** deletes them, after one question.

   **New group** makes a group of the selected measurements. You can also drag measurements onto a
   group, or onto **Ungrouped**: drag a selected row to move all the selected rows.

   <Screenshot id="measure/map--list" />

6. Click **Save Measurements** to save them in the dataset.

7. To use the measurements in another program, click **Export Measurements as GeoJSON** or
   **Export Measurements as CSV**. The CSV opens in Excel or any spreadsheet.

   <Screenshot id="measure/map--export" />

</Steps>

## Select measurements in the list

| Action | What it does |
| --- | --- |
| Click a row | Selects only that row |
| `Ctrl`+click (`Cmd`+click on a Mac) | Adds the row to the selection, or removes it |
| `Shift`+click | Selects all the rows from the last row you clicked |
| Check box of a row | Adds the row to the selection, or removes it (on a touch screen too) |
| Check box of a group | Selects all the rows of the group, or none of them |
| **Select all** | Selects all the rows that the search and the filters show |
| `↑` `↓` `Home` `End` | Move in the list and select the row. With `Shift`, the selection grows |
| `Space` | Adds the row to the selection, or removes it |
| `Enter` | Opens the properties of the row |
| `Ctrl`+`A` (`Cmd`+`A`) | Selects all the rows that the list shows |
| `Delete` | Asks to delete the selected measurements |
| `Esc` | Clears the selection. With no selection, closes the list |

A search or a filter removes the rows that it hides from the selection, so an action never changes a
measurement that you cannot see. Changes in the list are on the map only until you click
**Save Measurements**.

## Keys and gestures

Every measuring and drawing tool of the map (measure, annotation, **Profile**, **Area**, **Inspect**,
the stockpile tools) uses the same gestures. A tool that takes one point or two corners ends by itself:

| Gesture | What it does |
|---|---|
| Left click | Adds a point |
| Right click, double-click or `Enter` | Finishes the shape |
| `Esc` | Cancels it: nothing is kept |
| Right-drag | Pans the map without finishing the shape (a right button released within a few pixels is a click) |
| `Space` | Adds a point at the crosshair that shows in the centre of the map, when the map has the focus, so you can draw without a pointer |

## Options

The first row of the toolbar has the drawing tools. The second row shows when there are
measurements.

| Button | What it does |
|---|---|
| **Point Annotation** | Puts a point with a description on the map. See [Point annotations](/hub-guide/measure/annotations.mdx). |
| **Measure Length** | Draws a line through two or more points and shows its length. |
| **Measure Area** | Draws a polygon and shows its area. |
| **Erase Measurement** | Deletes the measurement you click. |
| **Edit/Move Measurements** | Drag a point to move it. `Shift`+drag moves the whole measurement. Double-click opens the properties. `Ctrl+Z` undoes. `Esc` exits. |
| **Stop Measuring** | Cancels the current tool (`Esc`), and the shape you were drawing. |
| **Measurement List** | Opens the list of measurements and groups. |
| **Save Measurements** | Makes the saved file the same as the map. With nothing left on the map, it removes the saved measurements. |
| **Clear All Measurements** | Removes all measurements from the map. The saved file does not change until you save again. |
| **Export Measurements as GeoJSON** | Downloads the measurements, with their groups, as a GeoJSON file. |
| **Export Measurements as CSV** | Downloads one row per measurement as a CSV table. See [CSV columns](#csv-columns). |
| **Delete Saved Measurements** | Deletes the saved measurements from the dataset. |

### How lengths and areas are measured

Hub measures lengths and areas on the WGS84 ellipsoid, not on a sphere and not on a flat map. A
length is the sum of the geodesic distances between the points. An area is the area of the
polygon on the ellipsoid. The numbers are the same as the ones that `ddb` gives, and the area of
a polygon is the same as its 2D area in the [stockpile](/hub-guide/analyse/stockpile.mdx) panel.
The stockpile panel counts pixels, so its area can differ from the map's by the pixels along the
edge of the polygon. The result does not depend on the latitude: a 100 m line east to west
measures 100 m at 0° and at 70°.

### Units

| Value | Metric | Imperial |
|---|---|---|
| Length | m up to 100 m, then km | ft |
| Area | m² below 1 ha, ha below 100 km², then km² | ft² below 1 acre, then acres |

To change the units, click **Map Settings** on the map and select **Measurement Units**:
**Metric** or **Imperial**. If there are measurements on the map, the **Change Units** dialog asks
first. Click **Convert** to show all measurements in the new units. If you can write the dataset,
Hub then saves them in the new units; if you can only read it, nothing is saved. The units
are the same setting as the **Units** tab of the [preferences](/docs/hub-guide/account/preferences),
so they follow your account. Saved lengths and areas show in your current units when they load.
The label of a [stockpile](/hub-guide/analyse/stockpile.mdx) on the map and its row in the
**Measurement List** follow the units too, after **Convert** and after you reload the page: with
**Imperial** they show yd³ and ST/yd³. The saved values stay metric.

### CSV columns

| Column | Content |
|---|---|
| `group` | The name of the group of the measurement, or empty |
| `name`, `description` | The name and the description from the properties |
| `type` | The kind of measurement: `length`, `area`, `point`, `stockpile` … |
| `value`, `unit` | The length or the area in the units the map shows. A stockpile has its net volume in m³ or yd³; a point has no value |
| `longitude`, `latitude` | The position of a point, in WGS84 |
| `wkt` | The shape of the measurement as WKT, in WGS84 |

Other properties of the measurements follow in more columns.

### Coordinates of a point

The label of a point shows its position in WGS84 in two formats: degrees, minutes and seconds,
and decimal degrees (6 decimals). The properties of a point have a button that copies the
coordinates as `latitude, longitude`.

## Limits & requirements

- **Save Measurements** shows only for users with write access to the dataset.
  **Delete Saved Measurements** shows only for users who can delete in the dataset.
- The measurements belong to the files on show. With **one file** on the map, Hub saves them next to
  it, with `_measurements.geojson` in place of the extension: `odm_orthophoto.tif` saves
  `odm_orthophoto_measurements.geojson`. With **anything else**, they belong to a
  `measurements.geojson` file in the folder of the first file on show: a folder selected in the file
  tree (its files are on the map), several files, or a map viewer with a base file and layers. In the root
  of the dataset the file is `measurements.geojson`. The raster that **Stockpile Volume** or **Raster Analysis**
  works on does not change the file.
- Measurements that an older version saved for a folder are in the `_measurements.geojson` of its first
  raster. They stay there, and show when you open that file alone.
- The map and the [point cloud viewer](/hub-guide/measure/3d.mdx) use the same file for the same point cloud.
  Each view saves and deletes only its own measurements, and keeps the measurements and groups
  of the other view in the file.
- Hub writes the file in format 2.0. A file in an older format opens as it is and is upgraded the
  next time you save. Opening a file never changes it.
- When the files on the map change so that the measurements belong to another file, and you have unsaved
  changes, Hub asks **Save the measurements to … before showing …?** **Save** writes them to the file
  they were made in, and then Hub shows the other file. **Discard** drops them. **Keep editing** (or
  closing the question) keeps them on the map, still in their own file: the measurement list shows
  **Saved in …** with that file. When you save them later, Hub shows the measurements of the new
  file. A user without write access cannot save, so Hub drops them and shows a warning. If **Save**
  fails, the map stays on the first file.
- Leaving the page with unsaved measurements (another page, a reload, closing the tab) asks first. On
  the map viewer, the question is the one about the view, with the measurements in it.
